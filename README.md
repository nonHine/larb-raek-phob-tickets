# ระบบจำหน่ายบัตรและตรวจสอบสลิป — "งานลาบแรกพบ"

ระบบเว็บแอปพลิเคชันขายบัตรคอนเสิร์ตดนตรีสดและตรวจสลิปโอนเงิน สำหรับงาน **"งานลาบแรกพบ"** ณ ร้านลาบก้อยซอยนานา (หลัง ม.ข.) 
ออกแบบมาเพื่อรองรับการใช้งานบนโทรศัพท์มือถือเป็นหลัก (Mobile-First)

---

## 1. จุดเด่นของระบบ
- **บัตรราคาเดียว:** 20 บาท/ใบ ไม่มีรอบ ไม่แบ่งโซน ไม่ต้องล็อกที่นั่ง
- **ชำระเงินสะดวก:** PromptPay QR พร้อมระบุยอดเงินตรงตามจำนวนบัตร (20 × N) พร้อมเลขบัญชีธนาคารสำรอง
- **ยืดหยุ่นในการโอน:** รองรับการโอนเต็มจำนวน หรือการแบ่งจ่ายหลายสลิป (Split payment) ในออเดอร์เดียว
- **ตรวจสลิปฉับไวสำหรับสตาฟ (`/admin`):**
  - คิวรีเฟรชอัตโนมัติทุก 5 วินาที พร้อมเสียงเตือนเมื่อมีสลิปใหม่
  - ออกแบบสำหรับใช้งานด้วยมือเดียวบนมือถือ
  - ระบบตรวจจับและเตือนสลิปซ้ำ (Duplicate detection ด้วย SHA-256 และเวลา/ยอดเงิน)
  - กลไกป้องกันสตาฟแย่งกันกดอนุมัติสลิปเดียวกัน (Idempotent approval)
- **สแกนตรวจบัตรหน้างาน (`/staff/scan`):**
  - สแกน QR Code ครั้งเดียวเพื่อมอบสายรัดข้อมือ (wristband)
  - ป้องกันการนำบัตรเดิมมาสแกนซ้ำ (Atomic check-in) พร้อมแสดงเวลาและสตาฟที่สแกนครั้งแรก
  - มีระบบค้นหาข้อมูลด้วยตนเอง (`/staff/search`) เมื่อกล้องมีปัญหา
- **สวิตช์ควบคุมร้านเต็ม (`venue_status.is_full`):**
  - สตาฟสามารถกดเปิด-ปิด "ร้านเต็มชั่วคราว" จากแถบเมนูด้านบนได้ตลอดเวลา
  - เมื่อเปิดสวิตช์ ระบบจะปิดรับออเดอร์ใหม่ทันที แต่ออเดอร์เดิมยังแนบสลิป ตรวจสลิป และสแกนเข้างานได้ตามปกติ

## 4. คู่มือการปฏิบัติงานในวันงานจริง (Event-Night Runbook)

### สำหรับสตาฟตรวจสลิป (Admin Reviewer):
1. เปิดหน้าเว็บ `/admin/login` บนมือถือและเข้าสู่ระบบ
2. อยู่ที่หน้าหลัก **"รอตรวจสลิป"** แตะเปิดปุ่ม **"เปิดเสียงเตือน"** เพื่อให้มีเสียงแจ้งเตือนเมื่อมีสลิปเข้ามาใหม่
3. เมื่อมีสลิปเข้ามา แตะที่การ์ดเพื่อเปิดดูภาพสลิป:
   - ตรวจสอบยอดเงิน วันที่ และบัญชีปลายทาง
   - หากมีแถบเตือนสีแดง **"เตือนสลิปซ้ำ"** ให้ตรวจสอบอย่างละเอียดว่ามีการนำสลิปเก่ามาใช้ซ้ำหรือไม่
   - หากยอดเงินตรง แตะปุ่มเขียว **"อนุมัติ"** 1 ครั้ง ระบบจะออกบัตร QR Code ให้ผู้ซื้อทันที
   - หากยอดเงินไม่ตรง ให้กดแก้ไขยอดเงินตามที่โอนจริง แล้วจึงกดอนุมัติ

### สำหรับสตาฟประตูหน้างาน (Gate Scanner):
1. เปิดหน้า `/staff/scan` บนมือถือแนวตั้ง
2. ให้ผู้เข้าร่วมงานเปิด QR Code จากหน้าสถานะออเดอร์ในมือถือของตน
3. ใช้กล้องสแกน QR Code:
   - **ขึ้นสีเขียว "เช็กอินสำเร็จ":** มอบสายรัดข้อมือ (wristband) ให้ผู้เข้าร่วมงานทันที
   - **ขึ้นสีแดง "บัตรนี้เข้างานแล้ว":** ไม่อนุญาตให้เข้า เนื่องจากมีผู้ใช้สิทธิ์บัตรใบนี้ไปแล้ว
   - **ขึ้นสีแดง "บัตรไม่ถูกต้อง":** ขอชื่อหรือเบอร์โทรผู้ซื้อ แล้วแตะปุ่ม **"ค้นหาด้วยตนเอง"** เพื่อตรวจสอบในระบบ

### เมื่อโต๊ะหรือพื้นที่ในร้านเต็ม:
- สตาฟคนใดก็ได้สามารถแตะปุ่ม **"กดปิดร้านชั่วคราว"** ที่แถบเมนูด้านบน แล้วกดยืนยัน ระบบจะหยุดรับการสั่งซื้อใหม่บนหน้าเว็บทันที
- เมื่อมีพื้นที่ว่าง ให้แตะปุ่มเดิมอีกครั้งเพื่อเปิดรับออเดอร์ใหม่
